# User Journey: Deploy AI Chat Agent

## User Persona
- **Who**: Product or operations owner at an SME
- **Goal**: Deploy an AI chat agent quickly to reduce support load and capture leads
- **Context**: Desktop or mobile, limited dev resources, needs quick win
- **Success Metric**: Critical tools live in <30 minutes; first leads captured within 24 hours

## Journey Stages

### Awareness
**Doing**: Discovers Mobiwave AI via search or referral
**Thinking**: "Can this replace basic support?"
**Feeling**: Curious, cautious
**Pain**: Hard to evaluate without trying
**Opportunity**: Clear trial limits and demo chat on landing

### Exploration
**Doing**: Reads features, how-it-works, and pricing
**Thinking**: "How easy is integration?"
**Feeling**: Hopeful, looking for low-friction setup
**Pain**: Unclear implementation steps for non-devs
**Opportunity**: One-line embed, clear developer docs, and screenshot previews

### Action
**Doing**: Signs up and embeds widget or requests API access
**Thinking**: "Did I configure training data correctly?"
**Feeling**: Slightly anxious, wants reassurance
**Pain**: No immediate confirmation of correct setup
**Opportunity**: Verification checks, visible progress, and contact options

### Outcome
**Doing**: Agent answers queries, captures leads
**Thinking**: "Is this reducing work?"
**Feeling**: Confident if metrics improve
**Success metrics**: Reduced tickets, increased conversions
